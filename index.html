MS thesis, in progress

Multi-resident activity recognition from simulated homes

Real smart-home datasets rarely say which resident triggered which sensor, and labelling that by hand doesn't scale. I extend AgentSense with multi-agent VirtualHome simulation, where every sensor event comes out already tagged with the resident who caused it. The synthetic streams are validated against CASAS Cairo and Kyoto.

It grew out of an 8-stage pipeline that generated per-resident streams, merged them with coordination rules, and repaired anything physically impossible. I compared four variants of it using Jensen-Shannon divergence, constraint-violation rates, and a random forest trained to tell real windows from synthetic ones.

Python / VirtualHome / AI Habitat / CASAS / scikit-learn / Pandas
Research reproduction

Reproducing LAHAR and MICAR

Working Python reimplementations of two LLM-based multi-resident methods, LAHAR on ARAS and MICAR on MARBLE, with real inference runs on Gemini. I wrote up the bugs I hit along the way, and a finding about evaluation: when one class such as sleeping dominates the ground truth, weighted F1 stops telling you much about the model.

Python / Gemini API / ARAS / MARBLE
