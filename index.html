Projects

The thesis, the reproductions behind it, and the applied work I do alongside.

MS thesis, in progress

Multi-resident activity recognition from simulated homes

Real smart-home datasets rarely say which resident triggered which sensor, and labelling that by hand doesn't scale. I extend AgentSense with multi-agent VirtualHome simulation, where every sensor event comes out already tagged with the resident who caused it. The plan is to validate the synthetic streams against the CASAS Cairo and Kyoto datasets.

The work is ongoing, so results will come with the thesis. It grew out of an earlier 8-stage pipeline that generated per-resident sensor streams, merged them with coordination rules, and repaired anything physically impossible.

Python / VirtualHome / AI Habitat / CASAS / scikit-learn / Pandas
Research reproduction

Reproducing LAHAR and MICAR

Python reimplementations of two LLM-based multi-resident methods, LAHAR on the ARAS dataset and MICAR on MARBLE, running end to end with Gemini. Rebuilding them is how I learn where existing approaches hold up and where they don't. Part of the thesis, still in progress.

Python / Gemini API / ARAS / MARBLE
